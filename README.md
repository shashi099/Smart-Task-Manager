# Smart-Task-Manager
Smart Task Management System  Build an application where users can create, assign, update, and track tasks.  Features  Create, update, delete, and view tasks User registration, login, and role-based access  REST APIs and database relationships  Stack: Spring Boot, Spring Data JPA, PostgreSQL, Spring Security, REST API

**DEPENDENCY ADDED IN THIS PROJECT TILL NOW**

* **Spring Web**:- Build REST APIs and handle HTTP requests.
* **Spring Data JPA**:- Interact with the database using repositories and entities.
* **PostgreSQL Driver**:- Connect Spring Boot to PostgreSQL.
* **Validation** :- Validate incoming API data.
* **Spring Boot DevTools**:- Speed up development with automatic restarts.

**pom.xml** is the Maven Project Object Model file. It defines project dependencies, plugins, build settings, and other project configuration. Maven reads this file to download required libraries and build the application.

**Important concepts:**
* @SpringBootApplication enables Spring Boot's main configuration, auto-configuration, and component scanning.
* main() is the entry point of the Java application.
* SpringApplication.run() starts the Spring application context and embedded web server for this web project.

**com.shashi.taskmanager**

* **controller/**  :- Handles HTTP requests and responses 
* **service/** :- Contains business logic
* **repository/** :- Communicates with the database
* **entity/** :- Maps Java classes to database tables
* **dto/** :- Defines API request and response objects
* **exception/** :- Handles application errors consistently
* **config/** :- Contains application configuration
* **security/** :- Authentication and authorization, added later
* **TaskmanagerApplication.java** :- Main entry point of the application

For example, when a user creates a task:
1. The Controller receives the task details.
2. The Service checks business rules, such as whether the task title is valid.
3. The Repository saves the task.
4. PostgreSQL stores the data.
5. The response travels back to the frontend.

**Understand the database connection**

**Here's how the components work together:**

* **Spring Boot** loads your application configuration.
* **Spring Data JPA** provides repository abstractions for database operations.
* **Hibernate** implements JPA and translates entity operations into SQL.
* **JDBC driver** enables Java to communicate with PostgreSQL.
* **PostgreSQL** stores the application's persistent data.

**Why use enums instead of strings?**

An enum restricts a field to a defined set of values. For example, task status cannot accidentally become "COMPLETEED" because of a spelling mistake.

###### **Notice that id and createdAt don't have public setters.** The database generates the ID, and the @PrePersist method sets the creation timestamp when a new entity is persisted.

## Understand the important annotations

 **@Entity**
Marks Task as a JPA entity that Hibernate can persist.

**@Table(name = "tasks")**
Specifies the database table name as tasks.

**@Id**
Marks id as the entity's primary key.

**@GeneratedValue**
Configures automatic ID generation. IDENTITY uses the database's identity-generation mechanism.

 **@Column**
Configures column properties, such as nullability and length.

 **@Enumerated(EnumType.STRING)**
Stores enum names such as IN_PROGRESS instead of ordinal numbers such as 1.

 **@PrePersist**
Runs the annotated callback before a new entity is inserted into the database.
